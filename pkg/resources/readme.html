装好后怎么用

  1. 完全退出 MuseScore（⌘Q），再重新打开乐谱
  2. 按 F10 打开混音器
  3. 找一个不用的乐器轨道（比如 Finger Snap，不用给它写音符）； 也可以按 I 新增一个乐器
  4. 这一轨的 Sound 列 → 下拉 → 选 大伟鼓谱MuseScore音频播放器
  5. 点 Sound 那一格，弹出插件界面
  6. 把音频文件拖进窗口（或点「打开音频…」按钮）

对齐音频和谱面

  • 拖动波形 = 定位播放头
  • ⌘拖动 / ⌥拖动 = 改起始偏移（配合 ⇧ 变 0.1 倍微调）
  • 滚轮 = 平移视野；⌥/⌘滚轮、双指捏合 = 缩放；双击 = 回到全览
  • 速度（BPM） 要填对——网格小节线才会和谱面真实小节对齐 （MuseScore 不向插件提供速度，默认按 120 画）
  • 拍号 按 N/M 填，如 4/4、12/8
  • 回到谱面 一键把音频播放头跳回谱面当前位置

常见问题

  • 混音器里看不到插件？→ 必须 ⌘Q 完全退出 MuseScore 再重开
  • 音频和谱子对不上？→ 放大波形，用 ⌥拖动网格让线条落在鼓点上
  • 插件操作后宿主崩了？→ 看日志 ~/Library/Logs/DaweiDrumScore.log

卸载

删除下面这个文件夹，然后重启 MuseScore 即可：

/Library/Audio/Plug-Ins/VST3/大伟鼓谱MuseScore音频播放器.vst3
