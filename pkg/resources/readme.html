装好后怎么用

  1. 完全退出 MuseScore（⌘Q），再重新打开乐谱
  2. 按 F10 打开混音器
  3. 找一个不用的乐器轨道（比如 Finger Snap，不用给它写音符）； 也可以按 I 新增一个乐器
  4. 这一轨的 Sound 列 → 下拉 → 选 大伟鼓谱MuseScore音频播放器
  5. 点 Sound 那一格，弹出插件界面
  6. 把音频文件拖进窗口（或点「打开音频…」按钮）

对齐音频和谱面

先记住一句：红线「音频」和绿线「谱面」平时本来就是重合的—— 它们只在播放出故障时才分开。别拿这两条线判断偏移调没调对； 唯一的标准是网格小节线有没有落在波形里的鼓点（第一拍）上。

  • ⌘拖动 / ⌥拖动波形 = 左右拖网格线，也就是改「起始偏移」。 把「1」那条小节线拖到音乐的第一拍上就对好了（配合 ⇧ 变 0.1 倍微调）
  • 偏移为正 = 跳过音频开头的一段（这一段会画成灰色）；为负 = 先垫一小段静音
  • 拖歪了不用往回拖：偏移旁边有 「归零」 按钮，点一下偏移立刻清零 （偏移范围是 ±3600 秒，拖到很大值时反向拖回来要拖好几个屏）
  • 按住拖动波形 = 平移视野（抓手，不改变播放位置，也不动偏移）
  • 滚轮 = 平移视野；⌥/⌘滚轮、双指捏合 = 缩放；双击 = 回到全览
  • 窗口可以拉宽：拖编辑器窗口的边缘即可，波形区会跟着一起变宽 （音频工具最需要横向分辨率）
  • 网格线跟谱子的小节对不上？ 先把 速度（BPM） 和 拍号 填对 —— MuseScore 不向插件提供速度（默认按 120 画）。拍号按 N/M 填，如 4/4、12/8
  • 红线 = 音频播到哪，绿线 = 乐谱播到哪。播放时它们黏在一起是正常的
  • 找不到播放头、或两条线分开了 → 点「回到播放头」： 它把音频跳回谱面当前位置（+偏移）重新同步，并把画面带回播放位置
  • 播放中若两条播放头分开，波形区右上角会亮出红色错位徽标 —— 那是跟随出故障（不是偏移没调好），点一下「回到播放头」即可修复
  • 若点了「回到播放头」之后几秒内又亮起来，说明跟随机制本身失效了 —— 徽标会改提示「跟随可能已失效 · 建议重启插件」，并把那一刻的错位量 记进日志 ~/Library/Logs/DaweiDrumScore.log

不会用？点界面上的「？帮助」

右上角 ？帮助 会弹出一份盖住整个面板的使用指南，按 实际操作顺序排：装音频 → 填速度 → 对拍子 → 波形区手势与快捷键 → 出问题怎么办。点任意处关闭。纯离线内置。

常见问题

  • 混音器里看不到插件？→ 必须 ⌘Q 完全退出 MuseScore 再重开
  • 音频和谱子对不上？→ 放大波形，用 ⌥拖动网格， 把「1」那条小节线拖到音乐的第一拍（波形里的鼓点）上
  • 画面跑到别处了？→ 点「回到播放头」跳回播放位置
  • 点了「回到播放头」还是错位？→ 徽标提示「跟随可能已失效」时， ⌘Q 完全退出 MuseScore 再重开（错位量已写进日志）
  • 插件操作后宿主崩了？→ 看日志 ~/Library/Logs/DaweiDrumScore.log
